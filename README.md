# کوردسەب — ئەپی ئایفۆن (iOS)

سۆرسی تەواوی ئەپی ئایفۆنی کوردسەب (Expo / React Native):
لینکی یووتیوب → ژێرنووسی دووزمانەی کوردی → **دابینگ بە دەنگی AIی کوردی** — هەمووی لەسەر ئایفۆنەکەت.

## ئەوەی من بۆم ئامادە کردووە ✅

- تەواوی کۆدەکە (دوو شاشە: سەرەکی + پەخشکردن)
- ژێرنووسی دووزمانە لەسەر ڤیدیۆکە، دەقی کاتدار، دابەزاندنی SRT
- دوگمەی 🔊 دابینگ بە دەنگی کوردی (لەگەڵ سێرڤەرەکە قسە دەکات)
- ڕێکخستنەکانی بویلد (`eas.json` + `app.json`)

## ئەوەی تەنها تۆ دەتوانیت بیکەیت (٣ هەنگاو — ناکرێت لەبری تۆ بکرێت)

بویلدی iOS پێویستی بە **هەژماری Apple Developer**ـە — ئەمە بە ناو و پارەی تۆوە دەبێت، بۆیە ناتوانم لەبری تۆ بیکڕم:

### هەنگاو ١ — هەژماری Apple Developer ($99/ساڵ)
1. بڕۆ بۆ [developer.apple.com](https://developer.apple.com) → **Enroll**
2. بە Apple IDـەکەت بچۆ ژوورەوە و پارەکە بدە ($99/ساڵ)
3. پشتڕاستکردنەوەی ناسنامە ١-٢ ڕۆژ دەخایەنێت — چاوەڕوانبە تا ئەکتیڤ دەبێت

### هەنگاو ٢ — ئامادەکاری لەسەر کۆمپیوتەرەکە
1. [Node.js LTS](https://nodejs.org) دابمەزرێنە
2. ئەم فۆڵدەرە بکەرەوە لە Terminal/PowerShell و ئەم فەرمانانە بنووسە:
```
npm install -g eas-cli
eas login
```
3. هەژمارێکی بێبەرامبەری Expo دروست بکە (ئەگەر هەتە بچۆ ژوورەوە)
4. لەناو فۆڵدەری `kurdsub-app`:
```
npm install
npx expo install --fix
eas build:configure
```

### هەنگاو ٣ — بویلدەکە
```
eas build -p ios --profile preview
```
- کاتێک پرسیاری Apple ID کرد، ئەو Apple IDـە بنووسە کە Developerـەکەی پێ کڕیوە
- تیمەکەت هەڵبژێرە — بویلدەکە لەسەر کۆمپیوتەرەکانی کڵاودی Expo دەکرێت (~١٥-٣٠ خولەک)
- لە کۆتاییدا لینکێکی دامەزراندن وەردەگریت → لە ئایفۆنەکە بکەرەوە و ئەپەکە دابمەزرێنە

## دوای دامەزراندن

1. لەسەر کۆمپیوتەرەکە `run.bat`ـی کوردسەب کار بکە (سێرڤەرەکە)
2. لە ئەپەکە ناونیشانی سێرڤەرەکە بنووسە — بۆ نموونە `http://192.168.1.5:5000`
   (ئەو ناونیشانەی کۆمپیوتەرەکە پیشانی دەدات؛ مۆبایل و کۆمپیوتەر لەسەر هەمان وایفای بن)
3. لینکی یووتیوب دابنێ و سەیر بکە 🎬

## تێبینییەکان

- بۆ نوێکردنەوەی دواتر پێویست نەکات بویلدی نوێ بکەیت: `eas update` بەکاربهێنە (نوێکردنەوەی هەوایی).
- ئەگەر دەتەوێت لە App Store بڵاوی بکەیتەوە: `eas build -p ios --profile production` پاشان `eas submit`.
